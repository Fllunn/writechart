# Spec Delta

## Purpose

Страница, на которой пользователь вводит код и сразу видит блок-схему: поле кода, выбор языка, схема, сообщения об ошибках и предупреждениях.

## ADDED Requirements

### Requirement: Главная страница показывает поле кода и схему
Страница `/` SHALL показывать поле для кода с номерами строк, выбор языка и область схемы. На широком экране поле SHALL стоять слева, схема — справа; на узком — друг под другом.

#### Scenario: Открытие страницы
- **WHEN** пользователь открывает `/`
- **THEN** он видит поле кода с номерами строк, выбор языка и схему

### Requirement: Схема помещается в свою область
Схема SHALL уменьшаться по ширине области схемы и SHALL NOT показываться крупнее своего размера 100 %.

#### Scenario: Широкая схема
- **WHEN** схема шире области
- **THEN** она уменьшена до ширины области, горизонтальной прокрутки нет

#### Scenario: Узкая схема
- **WHEN** схема уже области
- **THEN** она показана в размере 100 %

### Requirement: При открытии вставлен пример
При открытии страницы поле SHALL содержать пример программы на Python с вводом, ветвлением, циклом и выводом, и схема примера SHALL быть построена.

#### Scenario: Схема примера
- **WHEN** пользователь открывает `/` и ничего не вводит
- **THEN** в области схемы есть «Начало», ромб с подписями «да» и «нет» и «Конец»

### Requirement: Выбор языка
Выбор языка SHALL содержать пункт «Python», выбранный по умолчанию. Других пунктов в этой версии нет.

#### Scenario: Список языков
- **WHEN** пользователь открывает выбор языка
- **THEN** в списке один пункт «Python», он выбран

### Requirement: Схема обновляется при наборе
Схема SHALL перестраиваться после каждого изменения кода без кнопки «Построить». Код SHALL NOT отправляться на сервер.

#### Scenario: Правка кода
- **WHEN** пользователь меняет `print(s)` на `print(s, n)`
- **THEN** схема показывает `Вывод: s, n` без нажатия кнопок

#### Scenario: Код не уходит на сервер
- **WHEN** пользователь вводит код
- **THEN** страница не отправляет код ни на один адрес

### Requirement: Tab вставляет отступ
Клавиша Tab в поле кода SHALL вставлять отступ из четырёх пробелов в месте курсора, а не переводить фокус. Shift+Tab SHALL убирать до четырёх пробелов в начале строки.

#### Scenario: Отступ по Tab
- **WHEN** курсор в начале строки и пользователь нажимает Tab
- **THEN** в начале строки четыре пробела, фокус остаётся в поле

### Requirement: Ошибка в коде — схема устарела
Пока в коде есть ошибка, страница SHALL показывать последнюю удачно построенную схему бледной, с пометкой «схема устарела», и сообщения об ошибках с номерами строк. Номер строки с ошибкой SHALL быть выделен в колонке номеров. После исправления схема SHALL сразу обновиться и стать обычной.

#### Scenario: Забыто двоеточие
- **WHEN** пользователь удаляет двоеточие после `while i <= n`
- **THEN** прежняя схема остаётся, бледная, с пометкой «схема устарела»
- **AND** под схемой сообщение с номером этой строки
- **AND** номер строки выделен

#### Scenario: Исправление
- **WHEN** пользователь возвращает двоеточие
- **THEN** схема обычная, пометки и сообщения нет

#### Scenario: Ошибка с самого начала
- **WHEN** удачной схемы ещё не было, а код с ошибкой
- **THEN** область схемы пустая, под ней сообщение об ошибке

### Requirement: Предупреждения показываются под схемой
Предупреждения о неподдерживаемых конструкциях SHALL показываться списком под схемой, каждое с номером строки.

#### Scenario: Код с for
- **WHEN** в коде есть `for` в строке 3
- **THEN** схема построена, под ней предупреждение «Строка 3: for пока не поддерживается»

### Requirement: Долгая обработка не вешает страницу
Если построение схемы не закончилось за 2 секунды, оно SHALL прерываться, а страница SHALL показывать сообщение «Схема строится слишком долго» и оставаться отзывчивой.

#### Scenario: Тяжёлый код
- **WHEN** построение идёт дольше 2 секунд
- **THEN** оно прервано, поле кода по-прежнему принимает ввод, под схемой сообщение

### Requirement: Схема на странице не исполняет код
Перед вставкой в страницу SVG SHALL проходить очистку, которая удаляет скрипты, обработчики событий и ссылки. Текст из кода пользователя SHALL NOT исполняться на странице.

#### Scenario: Скрипт в коде
- **WHEN** пользователь вводит `print("<img src=x onerror=alert(1)>")`
- **THEN** на схеме этот текст виден как текст, диалог не появляется
