# Proposal

## Why

Главная функция Writechart — блок-схема по ГОСТ 19.701-90 из кода — ещё не существует. После `setup-core-scaffold` есть пустой пакет `core/`. Это изменение делает первую рабочую версию: студент вставляет код на Python и сразу видит схему (Начало → ввод → ромб «да/нет» → вывод → Конец). Объём и все решения — с грилинга 21.11.2026 (решения человека, Q1–Q22).

Второе из двух изменений. Требует слитого `setup-core-scaffold`.

## What Changes

- **Разбор Python на tree-sitter** (`web-tree-sitter` + `tree-sitter-python`, решение человека Q4). Ядро получает дерево разбора аргументом и от tree-sitter не зависит.
- **Модель в два шага** (Q7): структура программы (дерево, не зависит от языка) → чертёж (фигуры и линии с координатами в мм) → SVG.
- **Конструкции первой версии** (Q2): присваивание, `input`, `print`, `if`/`elif`/`else`, `while`. Неизвестная конструкция — блок с пометкой и предупреждение со строкой (Q17). Простой вызов функции — процесс.
- **Текст в блоках математикой** (Q15, Q16): `=`, `≠`, `≤`, `≥`, `mod`, `⌊a / b⌋`, `И`/`ИЛИ`/`НЕ`, `истина`/`ложь`, `·`, степень надстрочно, `+=` раскрывается; `Ввод n`; `Вывод: «Сумма:», s`.
- **Своя раскладка по ГОСТ** (Q3, Q8, Q12–Q14): фигуры по ряду ГОСТ (b = 1,5a, шаг 5 мм) под размер текста; терминатор — «таблетка»; `while` как на лабах человека; «да»/«нет» строчными; линии под прямым углом; стрелки только на линиях влево и вверх (правило — параметр).
- **SVG строит ядро** (Q9), шрифт Arimo с таблицей ширин букв в ядре (Q10, Q11; шрифт — параметр).
- **Защита** (Q9): SVG собирается только строителем с экранированием и белым списком; на странице SVG проходит DOMPurify; без внешних ссылок; лимиты размера; разбор и раскладка в Web Worker с остановкой по времени; видимые символы смены направления текста; код не уходит из браузера.
- **Проверка правил ГОСТ — функция ядра** (Q21): список нарушений по чертежу. Тесты: код → структура, правила ГОСТ на всех примерах, эталонные SVG, атаки.
- **Страница `/`** (Q19, Q20): `<textarea>` с номерами строк и Tab, справа схема, выбор языка (только Python), пример кода, ошибки и предупреждения внизу. Код с ошибкой → последняя удачная схема бледнеет с пометкой «схема устарела» (Q18).
- **E2E**: открыть `/`, увидеть схему примера, сломать код — увидеть сообщение.
- **Документация**: ADR-0017 (парсер tree-sitter), ADR-0018 (модель, своя раскладка, SVG в ядре, шрифт), `docs/architecture.md` (раздел «Устройство схем»), `core/AGENTS.md`, `frontend/AGENTS.md`.

Вне рамок: остальные языки, `for`, функции (`def`, предопределённый процесс), `break`/`continue`/`return`, `match`, соединители, комментарии ГОСТ, «граница цикла», экспорт (SVG/PNG/PDF/draw.io), полноценный редактор кода, выбор шрифта и настройка стрелок в интерфейсе, эллипс вместо терминатора, масштаб и перемещение схемы, сохранение, вход, тёмная тема. CSP страниц и заголовки экспорта — записываем требованием на изменения про деплой и экспорт.

## Capabilities

### New Capabilities

- `flowchart-generation`: превращение кода на Python в блок-схему по ГОСТ 19.701-90 в SVG — какие конструкции и как рисуются, текст в блоках, правила оформления, предупреждения, ошибки, лимиты и безопасность SVG.
- `flowchart-editor`: страница, где пользователь вводит код и видит схему — обновление при наборе, сообщения об ошибках и предупреждениях, устаревшая схема.

### Modified Capabilities

Нет.

## Impact

- Код: `core/src/` (конвертер Python, текст, раскладка, SVG, проверка ГОСТ, таблица шрифта), `core/scripts/` (генерация таблицы), `frontend/src/` (страница, поле кода, воркер), `e2e/tests/`.
- Новые зависимости (версии — в design): во `frontend/` — `web-tree-sitter`, `tree-sitter-python`, `dompurify`, `@fontsource/arimo`, `@writechart/core`; в `core/` dev — `web-tree-sitter`, `tree-sitter-python` (для тестов), `opentype.js`, `@fontsource/arimo` (для генерации таблицы).
- Корневой `package.json`: `dependenciesMeta` — не собирать нативную часть `tree-sitter-python`.
- `shared/` не меняется: модель схемы по API пока не ходит.
- Вес страницы: +~180 КБ gzip tree-sitter для Python (замер на грилинге) + DOMPurify + шрифт; wasm грузится в воркере.
