# ADR-0003: Express 5 + TypeScript для бэкенда

Статус: принято («пока») · 2026-11-17

## Контекст

Курс был по Node.js, фреймворк бэка должен быть из курса или с обоснованием. Сервис будет работать на своём сервере, поэтому важны низкие затраты памяти и CPU. Бэкенд обязательно на TypeScript.

## Решение

Node.js + TypeScript + Express 5 (последняя версия).

## Варианты

- **NestJS.** Самый тяжёлый из сравниваемых. По замеру на Node 24 (статья на dev.to): в покое 98 MB против 65 у Express и 72 у Fastify, запуск 320 ms против 116 и 153 ms, JSON 39k req/s против 51k и 72k.
- **Fastify.** Быстрее Express в том же замере, но команда выбрала Express как фреймворк из курса.
- **Go / Rust.** Отклонены: курс требует Node.js.
- **Hono, AdonisJS.** Рассматривались в сравнении, не выбраны.

## Последствия

- В Express нет встроенной проверки данных и описания API: используем Zod (ADR-0007).
- Структуру модулей задаём соглашением в `backend/AGENTS.md`.
- Официального MCP-сервера у Express нет; документация для агентов — через llms.txt и Context7 (подключение отложено).
