# ADR-0010: GitHub Flow, merge commit, Conventional Commits

Статус: принято · 2026-11-17

## Контекст

Команда из 4 человек, сайт без выпуска версий. На защите нужно показать вклад каждого через историю и графики GitHub.

## Решение

- **GitHub Flow:** `master` всегда рабочий; каждая задача в своей ветке; PR в `master`.
- **Защита `master`:** прямой пуш запрещён, слияние только при зелёном CI, одобрения не требуются.
- **Слияние:** merge commit через интерфейс GitHub.
- **Коммиты:** Conventional Commits со scope, например `fix(security): harden sessions`. Автопроверки (commitlint) пока нет.
- **Агенты не коммитят:** commit, push и PR делает человек (ADR-0011).

## Варианты

- Trunk-based — нужен сильный CI и флаги функций.
- git-flow — рассчитан на выпуск версий, для сайта лишний.
- Squash / rebase — история чище, но коммиты ветки не сохраняются как есть.

## Последствия

- В `master` попадают все коммиты ветки, поэтому сообщения важно писать по шаблону с самого начала.
