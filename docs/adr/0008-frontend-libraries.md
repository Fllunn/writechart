# ADR-0008: React Router, TanStack Query, Zustand, shadcn/ui

Статус: принято («пока») · 2026-11-17

## Контекст

SPA без метафреймворка (ADR-0002): роутер, работу с сервером, состояние и компоненты нужно выбрать самим. Во фронте два вида данных: те, что приходят с сервера (схемы, профиль, шаблоны), и те, что живут только в браузере (тема, выделенный блок, масштаб).

## Решение

- **React Router** — страницы и переходы.
- **TanStack Query** — данные с сервера: кэш, повторы при ошибке, обновление после изменений, без дублей запросов.
- **Zustand** — состояние интерфейса.
- **shadcn/ui** — компоненты, код которых лежит в проекте и меняется под нас.

## Варианты

- Роутер: TanStack Router.
- Данные: SWR, просто `fetch`.
- Состояние: Redux Toolkit, Jotai, React Context.
- UI: Mantine, MUI, Ant Design.

## Последствия

- Данные с сервера не копируются в Zustand.
- Редактор кода (CodeMirror или Monaco) выбирается вместе с устройством схем.
