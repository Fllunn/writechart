# ADR-0004: PostgreSQL

Статус: принято · 2026-11-17

## Контекст

Данные связаны между собой: пользователи, их схемы, история версий, шаблоны, роли для админки. Нужны транзакции и ограничения целостности. Курс требует обоснования выбора БД.

## Решение

PostgreSQL. Для разработки и тестов запускается в Docker (`docker-compose.yml`): основная база `writechart` и тестовая `writechart_test`.

## Варианты

- **MySQL / MariaDB.** Тоже подходят, но у PostgreSQL сильнее поддержка JSON (`jsonb`), что удобно для хранения схем.
- **MongoDB.** Данные реляционные, а гибкость документной модели нам не нужна.
- **SQLite.** Слабее при одновременной записи от многих пользователей.

## Последствия

- ORM пока не выбрана (Drizzle или Prisma 7), решение будет отдельным ADR.
- Тесты бэка работают с настоящей тестовой базой (ADR-0009).
