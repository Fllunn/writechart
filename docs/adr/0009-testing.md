# ADR-0009: Тесты, линтер и форматтер

Статус: принято · 2026-11-17 · линтер и форматтер заменены [ADR-0012](0012-ts7-oxc-tooling.md)

## Контекст

Курс требует автотесты в CI. Агентам нужны быстрые тесты: поменял код → за секунды увидел, что сломал. Одни только E2E-тесты медленные и не показывают, где ошибка.

## Решение

Пирамида тестов:
- **Vitest** — один запускатель для всех пакетов;
- **React Testing Library** (jsdom) — сложные формы и часть обычных компонентов;
- **Supertest** — тесты API Express без запуска сервера;
- **PostgreSQL `writechart_test` в Docker** — настоящая база в тестах, без моков;
- **Playwright** — E2E главных сценариев;
- ~~**ESLint + Prettier** — линтер и форматтер.~~ Заменено [ADR-0012](0012-ts7-oxc-tooling.md): Oxlint и oxfmt.

Минимальный процент покрытия пока не требуем.

## Варианты

- Jest вместо Vitest — отдельная настройка под Vite.
- Vitest Browser Mode вместо jsdom — честнее, но медленнее; вернёмся, если упрёмся в ограничения jsdom.
- Моки базы — быстрее, но не ловят ошибки SQL и миграций.
- Cypress вместо Playwright.
- Biome вместо ESLint + Prettier.
- Аналоги Supertest (скачивания в npm за неделю 09–15.11.2026): supertest — 25,6 млн; pactum — 0,1 млн; встроенный API-тестинг Playwright требует запущенного сервера.

## Последствия

- Инструменты ставятся отдельными изменениями OpenSpec.
- В CI нужен сервис PostgreSQL.
