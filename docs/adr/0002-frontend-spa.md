# ADR-0002: React + Vite SPA без метафреймворка

Статус: принято («пока») · 2026-11-17

## Контекст

Главная часть продукта — редактор, который работает в браузере: код вводится и схема перестраивается на лету. SEO и серверный рендеринг страниц не нужны. По требованиям курса нужен бэкенд + SPA или SSR-фронт, и бэкенд должен быть виден как отдельная часть.

## Решение

React + Vite, одностраничное приложение без метафреймворка.

## Варианты

- **Next.js.** SSR не нужен; бэкенд внутри Next.js хуже виден как отдельная часть проекта; из-за этого отклонён и Payload CMS, которому нужен Next.js.
- **Vue / Svelte.** Не рассматривались: команда выбрала React.

## Последствия

- Фронт — статические файлы, бэк — отдельный сервис.
- Роутер, загрузку данных и состояние выбираем сами (ADR-0008).
