# ADR-0006: Node.js 24 LTS

Статус: принято · 2026-11-17

## Контекст

Все участники и CI должны запускать одну мажорную версию Node. Её должны официально поддерживать все инструменты стека.

## Решение

Node.js 24 LTS. Закрепляется `.nvmrc` со значением `24` (подхватывают fnm, nvm и `actions/setup-node`) и полем `"engines": { "node": ">=24 <25" }`. Указана только мажорная версия, чтобы исправления безопасности приходили сами.

## Варианты

- **Node 26 (Active LTS с 28.10.2026).** Новее, но Vite 8 и Prisma 7 явно перечисляют только 20 / 22 / 24; Corepack с Node 25 больше не входит в поставку.
- **Node 22.** Поддержка заканчивается 30.04.2027.
- **Точная версия `24.x.y`.** Одинаково у всех, но обновления пришлось бы делать руками.

## Последствия

- Поддержка Node 24 заканчивается 30.04.2028 — с запасом на весь срок проекта.
- С октября 2026 Node 24 в режиме Maintenance (только исправления).
