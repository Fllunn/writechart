# ADR-0011: Разработка с ИИ — AGENTS.md и OpenSpec

Статус: принято · 2026-11-17

## Контекст

Курс требует агентной разработки (AI SDLC), AGENTS.md и скиллов в репозитории. Используем Claude Code и Codex. Агентам нужны постоянные правила и понятный процесс, чтобы они не писали код без согласованного плана.

## Решение

- **AGENTS.md** в корне (общие правила) и в `frontend/`, `backend/`, `shared/` (правила папки). `CLAUDE.md` подключает `AGENTS.md`.
- **OpenSpec** (spec-driven): любая работа начинается с изменения в `openspec/changes/`, человек утверждает proposal, агент выполняет `tasks.md`, после слияния изменение архивируется. OpenSpec установлен в проект (`@fission-ai/openspec`), его скиллы лежат в `.claude/skills/` и `.agents/skills/`.
- **Git — только человек:** агент не делает commit, push и PR, а предлагает текст. Технического запрета пока нет, только правило в AGENTS.md.

## Варианты

- **GitHub Spec Kit.** Строже и тяжелее, на Python; по сравнениям лучше подходит для старта с нуля.
- **Без spec-driven.** Меньше процесса, но агенты работают без согласованного плана.
- **Один AGENTS.md в корне.** Проще, но агент хуже знает правила конкретной папки.

## Последствия

- Каждое изменение оставляет в репозитории след: proposal, design, tasks. Это можно показать на защите.
- Свои и сторонние скиллы (superpowers, Matt Pocock) пока не добавлены.
- MCP-серверы (в том числе Context7) и ИИ-ревью PR не подключены.
