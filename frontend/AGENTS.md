# AGENTS.md — frontend

Сначала прочитай корневой [`../AGENTS.md`](../AGENTS.md): процесс OpenSpec и правила Git действуют и здесь.

## Что здесь

SPA для браузера: React + Vite. Решено, но пока не установлено:
- React Router — страницы и переходы;
- TanStack Query — всё, что приходит с сервера (кэш, повторы, обновление);
- Zustand — состояние интерфейса, которого нет на сервере (тема, выделенный блок, масштаб);
- shadcn/ui — компоненты интерфейса.

## Правила папки

- Данные с сервера держи в TanStack Query, не копируй их в Zustand.
- Типы и проверку данных API бери из `@writechart/shared`, не описывай их здесь второй раз.
- Не импортируй код из `backend/`.
- Импортируй библиотеки по конкретным путям, не через barrel-файлы с `export *`.
- Тесты (когда появятся): Vitest + React Testing Library для сложных форм и части обычных компонентов, Playwright для главных сценариев.
